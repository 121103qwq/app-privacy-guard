# 新电脑快速部署

部署工具适用于 Windows 10/11 x64。它保留 Windows 的语言和时区，针对已发现的 Claude 程序安装防直连规则和系统启动保护。
这是非严格方案，不能保证所有子进程、服务、浏览器和任意故障下都不泄漏地区信息。

## 准备

1. 从 [0.3.0 Release](https://github.com/121103qwq/app-privacy-guard/releases/tag/v0.3.0) 下载 `app-privacy-quick-deploy-0.3.0.zip`，完整解压。
2. 安装或准备官方签名的 Claude Desktop MSIX。工具不分发 Claude 安装包。
3. 若使用 Code，准备独立、由 Anthropic 签名的 `claude.exe`。共享 Node、符号链接和不同文件名的版本入口不自动覆盖。
4. 启动现有代理，使一个本地 HTTP 端口固定走美国节点。默认端口为 `17992`，地址为 `127.0.0.1`。

代理端口必须固定使用美国节点，无 DIRECT 回退。一次美国出口探测不证明其他域名也采用相同出口。工具不修改代理配置，也不导入节点和账号。

## 部署

打开解压目录中的 `AppPrivacyGuard.exe`，或 `deployment/Start.cmd`。
程序未使用 Windows 代码签名证书签名。Release 提供 SHA-256 校验文件。

1. 填写本地代理端口，点击“检查环境”。
2. Code 自动发现失败时，选择独立 `claude.exe`。Desktop 尚未安装时，可选择官方 MSIX。
3. 根据需要选择保护 Edge。勾选后，规则会影响该 Edge EXE 的所有资料，未通过本机代理的直接出网会失败。
   部署前关闭目标 Claude 和 Edge。若已有 Desktop 的 Cowork 服务仍在运行，在管理员 PowerShell 执行 `Stop-Service CoworkVMService`，再重试。工具保留已有会话，不强制关闭它们。
4. 点击“部署 / 更新保护”。Windows 会要求管理员权限，取消系统确认时不会显示部署成功。
5. 等待美国出口、WFP、启动钩子和地区探针检查完成。

工具先复制运行文件并保存原状态，再安排 SYSTEM 回滚任务。普通部署默认 3 分钟，含 MSIX 安装时为 5 分钟。
回滚进程会先独立运行探针。无法验证它具备必要权限时，不修改联网保护。
部署失败会立即恢复本次修改；失去当前会话时，定时任务仍可恢复。验收成功后才取消倒计时。

已有其他安装的启动钩子时，工具保留原状态并停止，避免覆盖既有保护。
更新已有官方 MSIX 应先通过官方途径完成，再点击“部署 / 更新保护”。安装期间新加入的程序和其他名称的更新文件，仍有覆盖缺口。

## 浏览器与登录

专用 Edge 不导入个人资料。首次使用仍需在 `edge://extensions/` 中确认 `App Privacy local Claude and Google region` 已启用。
如果没有加载，使用开发人员模式加载安装目录内的 `desktop/local/edge`。
安装目录通常为 `%ProgramFiles%\App Privacy Guard\0.3.0`。

点击“打开专用 Edge”，或使用创建的 Edge 快捷方式。登录页、Google 登录和返回 Claude 的页面应留在该专用资料中。
两个 Edge 的资料分别保存在当前用户的本地应用数据目录，即 %LOCALAPPDATA%\AppPrivacyGuard\edge-one 和 edge-two。日常写入资料不需要管理员权限。
启动钩子不会自动把浏览器授权切换到正确资料，扩展加载和真实授权兼容性仍需用户核对。工具不操作真实账号。

## 日常与撤销

先启动固定美国代理，再打开客户端。工具会创建可用的 Desktop、Code、组合启动和两个 Edge 快捷方式。
系统钩子覆盖普通 Windows 启动的 `claude.exe`。直接运行、命令行和协议启动会进入同一启动器，启动保护缺失或地区模块初始化失败时拒绝启动。
管理员或显式调试、重命名程序、共享运行时等方式可以超出该保护范围。

点击“检查保护”可检查当前路径、启动钩子和美国代理。检查成功不代表所有地区读取均已覆盖。
撤销前关闭目标 Claude 和 Edge 进程，然后点击“撤销本工具保护”。撤销也会先验证独立回滚任务；中途失败会恢复撤销前的保护。
工具只撤销其拥有的规则和启动钩子，保留程序、浏览器资料和原有保护。

同版本安装文件不同或已损坏时，工具拒绝覆盖正在使用的二进制文件。请使用新版本，或先恢复原版本文件。这个检查避免失败更新破坏旧保护的运行文件。

部署记录保存在 `%ProgramData%\AppPrivacyGuard`，只有管理员和 SYSTEM 可以写入。不将这些本机记录上传到仓库。
部署 ZIP 不需要 Node、Python 或编译器。它依赖 Windows PowerShell 5.1、.NET Framework 4.8 和任务计划服务。

本版本测试使用自有探针和空白配置，不使用真实账号。独立新电脑和完整真实登录的验收仍未完成。
